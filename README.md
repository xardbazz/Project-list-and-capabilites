# Project Portfolio

A curated portfolio of software, systems, infrastructure, design, and technical-writing work. Projects include personal experiments, home-lab work, and study assignments; they are not presented as commercial client deployments. Each entry links to a case study, source code, or article when available.

## Systems and Infrastructure

- **Offline voice assistant on ODROID-C2** — local speech recognition with Qwen2.5 through Ollama and Piper speech output; boot and audio troubleshooting on a 2 GB ARM board. [Case study](https://github.com/xardbazz/Project-list-and-capabilites/blob/main/Edge%20AI%20and%20Systems%20Engineering.pdf) · [Source code](https://github.com/xardbazz/light-AI-OdroidC2)
- **Windows 11 virtualization on Arch Linux** — booted an existing Windows installation as a VirtualBox VM while isolating the host EFI and GRUB setup. [Case study](https://github.com/xardbazz/Project-list-and-capabilites/blob/main/Windows%2011%20Virtualization%20on%20Arch%20Linux.pdf)
- **Arch Linux and Windows dual boot** — planned the EFI layout, configured GRUB and Windows detection, and set up NVIDIA drivers on one NVMe drive. [Case study](https://github.com/xardbazz/Project-list-and-capabilites/blob/main/Arch%20Linux%20%2B%20Windows%20Dual-Boot%20System.pdf)
- **Linux troubleshooting and recovery** — image-first SD-card recovery and APT repository/network diagnosis on an ARM board. [Case study](https://github.com/xardbazz/Project-list-and-capabilites/blob/main/Linux%20Troubleshooting%20and%20Recovery.pdf)
- **RustDesk rendezvous setup** — configured and checked the `hbbs` service on Windows. The case study distinguishes it from the separate `hbbr` relay and does not claim a full relay deployment. [Case study](https://github.com/xardbazz/Project-list-and-capabilites/blob/main/Networking%20%26%20Remote%20Access.pdf)
